# Security

Rutt/Etra Web runs entirely in the browser; the hosted site has no server-side code. The companion bridges in `tools/` (OSC, MCP) are meant to run on your own machine and listen on localhost by default.

If you find a security problem — for example a way for a shared project file, a share link or a stream URL to do something the person opening it didn't agree to — please report it privately through GitHub's **[Report a vulnerability](https://github.com/reillydonovan/RuttEtraWeb/security/advisories/new)** form rather than in a public issue. You'll get a reply as soon as possible.
